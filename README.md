## 三网优化优化的到底是哪一段？

优化的是回程，也就是数据从美国机房传回你手机和电脑的那一段。

很多人挑机器只看 ping 值，但 ping 主要测去程，而晚高峰掉速、看视频转圈、SSH 打字有延迟，基本都发生在回程。去程走国内运营商的国际出口，相对好走；回程走的是机房上游，那里才是国际拥塞最严重的地方。所谓三网优化，就是让电信、联通、移动三家用户的回程各有一条相对通畅的通道。

三条线路各管一家：

- **电信 CN2 GIA**：电信的高端承载网，晚高峰稳定性最好，价格也最贵。网上关于它的 ASN 有 AS4807 和 AS4809 两种写法，来源之间本身就不统一，别拿 ASN 当唯一判据，看商家标的回程路由更实在。
- **联通 AS9929（CUII）**：联通精品网，业内常把它和 CN2 GIA 放在同一档讨论，性价比更高。再往下一档是 AS4837（CUVIP），比普通 169 骨干稳，但不算精品网。
- **移动 CMIN2 / CMI**：移动侧的优化回程，带宽通常给得比较大方。CMIN2 和 CMI 在不同商家嘴里指的不是完全相同的产品，看到这两个词先确认具体路由。

市面上有两种卖法。一种是三网分线，电信 GIA、联通 9929、移动 CMIN2 各走各的，成本最高，套餐也最贵。另一种是回程统一走 9929，三网都吃联通精品网，均衡性和价格更好看。同一个词被用来指两种东西，所以“洛杉矶三网优化”这个说法本身没什么信息量，得看具体路由。

洛杉矶之所以成为这类机器的主要机房，是因为美西离亚洲近、海缆登陆点集中、原生 IP 池子大。走优化线路的洛杉矶机器延迟在 150ms 上下属于不错的水平，普通线路 200ms 以上是常态。香港能压到 30–40ms，日本约 100ms，但同配置价格往往是洛杉矶的两到三倍。要低延迟选香港日本，要大带宽大流量选洛杉矶。

## 常见问题

**晚高峰会不会掉速？**
SixtyNet 屏蔽 ping，你没法自己测延迟。它的联通回程走 AS9929、电信和移动走 CN2，这两条都是优化线路，晚高峰比普通国际出口稳。但任何线路高峰期都会波动，第三方测评也没有给出完整的早晚高峰对比数据。真在意，先买一个月，晚八点到十点自己跑一遍。

**住宅 IP 屏蔽 80 和 443，还能建站吗？**
技术上可以，用端口转发或者前置 CDN 把流量导进来。但这样一来配置复杂度和额外开销都上去了。纯建站需求不建议走住宅线。

**双 ISP 那 $5 值不值？**
只在业务明确需要双 ISP 属性时才值。跑流媒体解锁、单账号运营，单 ISP 完全够。多花的钱买的是一层风控上的保险，不是速度。

**优惠码在哪填？**
结账页底部的 Promotion 输入框，填完点 Validate Code。不生效通常是码过期或者不适用当前套餐，Pro 系列一般不参与折扣。

**能退款吗？**
Pro 系列官方写明退款只退到网站余额。其他系列页面没有标注退款口径，下单前问客服确认，别默认有几天无理由。
